## 구현할 기능 목록

---

### 입력

- [X]  구입 금액 입력  
  → 1,000원 단위로!!
- [X]  당첨 번호 6개 입력
- [X]  보너스 번호 6개 입력

### 출력

- [X]  구입한 로또 개수 만큼의 자동으로 로또 번호 목록 출력
- [X]  3개 일치한 경우부터 6개 일치한 경우까지 전부 당청 여부 출력 (당첨되지 않아도 0개로 출력)
- [X]  수익률 출력

### 기능

- [X]  입력된 금액의 유효성 검사
- [X]  구입 금액 / 1,000 한 개수 만큼 로또 번호 생성
- [X]  쉼표로 구분된 번호 분리 
- [X]  당첨 번호와 생성된 로또 번호와의 비교 후 당첨 여부 확인  
  → 정확히 5개가 일치할 경우에만 보너스 번호 비교하기  
  → 그 이외에는 보너스 번호 무쓸모
- [X]  구입 금액 대비 수익률 계산  
  → 소수 둘째 자리에서 반올림

### 예외 처리

- [X]  입력된 구입 금액이 숫자가 아닌 문자가 있을 경우
- [X]  구입 금액이 1,000원 단위로 나누어떨어지지 않는 경우
- [X]  입력된 당첨 번호에서 중복된 번호가 있을 경우
- [X]  보너스 번호가 기존 당첨 번호 6개와 중복이 있을 경우
